# RSS Source Evaluation

When evaluating articles from RSS feeds:

1. **Known high-quality sources** (GitHub Blog, official project blogs) get a slight trust bonus.
2. **Aggregators** (Hacker News) contain mixed quality — evaluate each item individually.
3. **Short excerpts** are common in RSS — do not penalize articles just because the excerpt is brief, but note the limitation.
4. **Duplicate content** across sources (e.g., the same announcement on multiple blogs) should favor the primary source.
5. **Staleness** — content older than the requested time window should not be included regardless of relevance.
